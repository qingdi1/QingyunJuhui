# 知识库

> 青云聚汇项目知识库（Obsidian vault：`docs/`）。

本目录用于沉淀事故案例、架构决策与经验教训，方便 agent 和人在后续合并、重构时快速检索，避免重复踩坑。

## 使用方式

- 用 Obsidian 打开仓库根目录或 `docs/` 作为 vault。
- 笔记之间用 `[[双链]]` 互相引用，正文可用 `#标签` 组织主题。
- 事故案例统一放在 `incidents/`，命名 `YYYY-MM-DD-简短标题.md`。
- 每个案例必须在下方索引登记。
