# 上游合并丢失国风UI与窗口按钮

## 摘要

将官方 `v1.2.49` 合并进青云聚汇分支后，出现三类问题：**国风 UI（墨韵主题）全部消失、侧边栏布局混乱、顶部关闭/缩小/最大化按钮全部消失**。根因是三方合并时错误偏向上游，且后续恢复时用错了自定义分支基线。

## 时间线

1. 合并官方 `v1.2.49`，产生合并提交 `25d21e3`，`styles.css` / `App.tsx` 等发生真实三方冲突，冲突解决时错误采用了官方侧。
2. 用户反馈：自定义 UI、修改的逻辑全部不见。
3. 第一轮修复（`db02c4b`）：定向恢复品牌文案、供应商卡、`Codex 1.5x Fast` 等，但样式仍是一堆冲突残留的混合体（多个主题变量集 + 13 个 `.sidebar` 定义）。
4. 第二轮修复（`506035a`）：误把 `decorations` 改为 `true`（走原生标题栏），并把 `styles.css` 恢复到了 **`12fa009`（fork 建立提交）**。
5. 用户指出国风 UI 仍未恢复。核对 `git log` 后发现：**国风 UI 是在 `12fa009` 之后的多个本地提交里实现的**，最新完整版是 `ed49c9e`。
6. 最终修复（`3db2daf`）：以 `ed49c9e` 为国风基线恢复 `styles.css`，追加 v1.2.49 新增的 84 个选择器块；恢复 `WindowTitlebar`、`InkCursorTrail`、`sidebar-art`；窗口恢复 `decorations: false`；补齐标题栏 i18n 键。

## 根因

### 1. 合并冲突错误偏向上游

官方 `v1.2.49` 与青云分支在 `styles.css`、`App.tsx`、`renderer-inject.js`、i18n、安装器等多处真实冲突。冲突解决时若整文件采用官方侧，会丢掉全部国风定制：

- 墨韵主题变量（`--cinnabar`、`--ochre`、`--mineral-blue`、`--paper-fiber`、`--ink-shadow` 等）
- `.window-titlebar` 自定义标题栏与窗口控制按钮
- `InkCursorTrail` 墨水光标、`sidebar-art` 水墨背景层

### 2. 恢复时用错基线

`12fa009 feat: establish Qingyun Juhui fork` 只是 fork 建立提交，国风 UI 是在其后这些提交中逐步加入的：

- `28e5a22` — 国风重构（`styles.css` +1332 行，新增水墨背景素材、图标）
- `7aaf235` / `9054145` — 水墨山侧边栏背景与可见性修复
- `b079b3e` — 顶部栏水墨画
- `f7f8e1f` — 自定义墨韵标题栏（替代原生标题栏）
- `00c5ded` / `4cd9538` / `ddd6e23` — 窗口控制按钮权限、拖拽区域修复

正确的国风基线是分支头 **`ed49c9e`（tag v1.2.43）**，而非 `12fa009`。

### 3. 窗口配置被反向修改

自定义标题栏依赖 `decorations: false` + 前端 `WindowTitlebar`。修复过程中曾误改为 `decorations: true`（原生标题栏），导致「顶部按钮消失」问题反复出现。

## 修复方案

```text
styles.css  = ed49c9e 国风基线（6565 行） + v1.2.49 新增 84 个选择器块
App.tsx    = v1.2.49 结构 + WindowTitlebar + InkCursorTrail + sidebar-art
lib.rs     = decorations(false)
tauri.conf = decorations(false)
capabilities = 保留 allow-close / allow-minimize / allow-start-dragging / allow-toggle-maximize
i18n       = 补齐 最小化窗口 / 最大化窗口 / 关闭窗口 / 青云聚汇 · 云台
```

追加选择器块的做法：从官方 `styles.css` 中提取「国风基线中不存在的选择器」的完整规则块，统一追加到文件末尾（带注释分隔），避免覆盖国风样式。

- `npm run check` 通过
- `node tools/i18n-verify.mjs`：plain 892/892，template 72/72
- `npm run build` 成功，产物 `F:\Community\qdcodex\target\release\qingyun-juhui-manager.exe`

## 关键提交

- `25d21e3` — 合并 v1.2.49（冲突错误）
- `db02c4b` — 恢复青云增强文案与逻辑
- `506035a` — 误用 12fa009 基线、误开原生标题栏
- `3db2daf` — 最终修复：恢复国风 UI 与自定义标题栏

## 预防措施

1. 合并前先确认本地分支头基线，禁止用 fork 建立提交当基线。
2. `styles.css` 只追加官方新增选择器块，绝不整文件采用上游或任一冲突侧。
3. 合并后逐项核对国风 UI 保护清单（见根目录 `AGENTS.md`）。
4. 涉及窗口按钮时先查 `decorations` 与 `WindowTitlebar` 是否成对存在。
5. 修复后必须跑 `npm run build` 并核对 EXE 时间戳，确保产物包含修复。
